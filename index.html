A QUICK TROUBLESHOOTING GUIDE

How to compare code online

  1. Paste or import the original and modified code.
  2. Select a file extension and choose side by side or unified view.
  3. Press Compare to see additions, deletions and word changes.
  4. For web problems, load both versions into the playground and compare their source, rendered layout and console output.

What is a code diff?

A code diff identifies changes between two versions of text. Added and removed lines help locate a regression, review a fix or check configuration changes. This comparator works with JavaScript, CSS, HTML, JSON, SQL, PowerShell and other text formats.

Does my code leave my browser?

The comparison runs in your browser. Snippets and imported project files are not uploaded or saved automatically. The page loads shared Mightora branding assets from external services. Downloads remain under your control.

Can I compare web page output?

Yes. Run two HTML, CSS and JavaScript projects in isolated frames at the same width. Compare the rendered pages visually and inspect each console. This is a manual visual comparison, not an automated pixel difference test.

Why can identical-looking snippets differ?

Spaces, line endings and a missing final newline can produce differences. Line endings are normalised for comparison. The whitespace option ignores leading and trailing spaces on each line, but retains changes within the line.

Can it run Python, C# or Node.js?

These files can be compared as text. The preview executes browser HTML, CSS and JavaScript only. Node.js, databases and backend applications need a separate runtime.

Is VS Code included or embedded?

No. The tool links to Microsoft’s VS Code for the Web and can launch an installed desktop editor. Code–OSS source is MIT licensed; Microsoft’s VS Code distribution has a separate product licence. See the official licence FAQ and Code–OSS licence.
